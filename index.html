AeroDuel

Abate o avião inimigo. Se fores atingido, salta de paraquedas e corre para o teu hangar para ires buscar outro avião!

Como se joga
  • Rodar: ↺ ↻  (teclado: ← → ou A D)
  • Disparar: FOGO  (Espaço ou J)
  • Saltar de paraquedas: SALTAR  (E ou K)
  • Pausa: P ou Esc
  • O avião acelera sozinho. Para descolar, espera que ganhe velocidade e puxa o nariz para cima.
  • Se subires a direito durante muito tempo perdes velocidade e entras em perda: aponta o nariz para baixo para recuperar.
  • Para aterrar, toca no chão quase na horizontal. Se passares pelo teu hangar, o avião fica reparado.
  • Avião abatido: +1 ponto. Piloto eliminado: +1 ponto. Se ficares dentro do avião quando ele cai, o adversário ganha os dois pontos, por isso salta!
  • No ar, guias o paraquedas com ↺ ↻. No chão, o piloto anda com os mesmos botões.
