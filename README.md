# AeroDuel ✈️

Jogo 2D de combate de biplanos para Android, inspirado nos clássicos *Biplanes* e *Bluetooth Biplanes* dos telemóveis Java. Pilotas um biplano, abates o adversário e, se fores atingido, saltas de paraquedas e corres até ao hangar para ires buscar outro avião.

## Estrutura do repositório

| Pasta | O que é |
|---|---|
| [`godot/`](godot/) | **O jogo a sério:** a app Android, feita em Godot 4. |
| [`webversion/`](webversion/) | O protótipo HTML/JavaScript onde se afinaram a física, o bot e o multiplayer online (PeerJS). Joga-se no browser e serve de referência. |

## Roteiro

1. **Base em Godot:** voo, tiro, paraquedas, hangares, bot, controlos táteis e APK gerado automaticamente.
2. **Conteúdo:** aviões diferentes, powerups e níveis de campanha com objetivos.
3. **Progresso:** moedas, XP, desbloqueáveis e gravação.
4. **Multiplayer online.**
5. **Publicação na Play Store.**
